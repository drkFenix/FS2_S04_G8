# Planilla de Requerimientos (Propuesta) - HuertoHogar

| ID | Nombre del Requerimiento | Descripción | Tipo | Estado |
| :--- | :--- | :--- | :--- | :--- |
| **REQ-01** | Registro de Usuarios | El sistema debe permitir crear una cuenta utilizando nombre, correo y contraseña con validaciones en cliente. | Funcional | Completado |
| **REQ-02** | Inicio de Sesión | El sistema debe permitir iniciar sesión verificando correo electrónico y contraseña (simulado). | Funcional | Completado |
| **REQ-03** | Catálogo por Categorías | El sistema debe organizar los productos en categorías: Frutas Frescas, Verduras Orgánicas, Orgánicos y Lácteos. | Funcional | Completado |
| **REQ-04** | Detalle de Productos | Cada producto debe mostrar su precio, stock actual y descripción detallada del origen. | Funcional | Completado |
| **REQ-05** | Flujo de Éxito | El sistema debe redirigir a una pantalla de éxito tras registrarse correctamente. | Funcional | Completado |
| **REQ-06** | Identidad Visual | La interfaz debe utilizar los colores corporativos (Verde Esmeralda, Amarillo, Blanco Suave) y fuentes (Montserrat, Playfair). | No Funcional | Completado |
| **REQ-07** | HTML Semántico | El código debe estar construido estrictamente usando etiquetas de HTML5. | No Funcional | Completado |
